# Branch Proof AI application

This directory contains the Angular client and Express API for Branch Proof AI.

See the [main project README](../README.md) for the project overview, architecture, environment setup, API routes, verification commands, and deployment roadmap.

## Quick start

```bash
npm ci
cp .env.example .env
npm run dev
```

The Angular client runs at `http://localhost:4200`, the Express API at `http://localhost:3000`, and Swagger documentation at `http://localhost:3000/api-docs`.
